# 22:00研究所

## Welcome

22:00研究所は、夜の時間を、自分の思考と向き合う時間に変えるためのラボです。

このプロジェクトは完成を目指すものではなく、問い・対話・レビューを繰り返しながら、自分自身とラボの両方を育てていくことを目的としています。

このREADMEも完成版ではありません。
研究を続ける中で更新されていきます。

---

## このラボで大切にしたいこと

* 問いを立てる
* 自分の考えを書く
* レビューを受ける
* 考えを更新する
* 小さくても継続する

---

## このラボが目指すもの

まだ答えは決まっていません。

このラボそのものを育てながら、
「自分にとって価値のある思考とは何か」を探していきます。
